# Ollama
- Ollama allows to install large language models locally on your machine.
- install from ollama.com
- verify installation
    - ollama --version
- olllama run llama3.1
- ollama run mistral
- ollama run gemma2
- Interacting with the model
    - command line
- Useful Ollama commands
    - ollama list
    - ollama pull llama3.1
- access ollama via api
    - default api server at http://localhost:11434, allowing you to connect it local UI frontends.
